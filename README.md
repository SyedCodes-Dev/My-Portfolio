# Syed Ahsan — Animated Developer Portfolio

A personal developer portfolio built with React, Vite, Tailwind CSS, GSAP and Lenis.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Portfolio content

Main portfolio content is centralized in:

- `src/data/portfolioData.js`
- `src/data/projectMeta.js`
- `src/data/projectDetailsData.js`

Project images live in `public/projects/` and the profile image is `public/profile.webp`.

## Current projects

- CricketHub
- ShopEase
- Luxury Restaurant
- Nature Parallax
- Finora Finance

Two additional project cards remain intentionally empty for future work.

## Deployment

Build output is generated with Vite. Deploy the generated output to a static host such as Netlify or Vercel. Configure SPA fallback routing so project detail URLs resolve to `index.html`.
